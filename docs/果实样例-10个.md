# 果实样例 10 个（v4 端口工作流）

载入方式：后台「果实管理」→ 技能列表底部 **载入预设** → 选名字 → 会新建一颗果实并自动排进泳道。
样例全部按 v4 端口连线（彩色边）编写，可直接在卡片里改参数、改端口、试放。

## 逐个说明

### 1. 冰锥三连（`rare` / 4.0s）
- 触发：定时循环 3.0s，首次延迟 0.4s，瞄准对手。
- 目标：单体，距离最近。
- 投递：投射物 ×3，扇形 26°，速度 340，射程 780。
- 结算：冰元素 8 + 8% 伤害，命中减速 40% / 2s；基础伤害 6。
- 表现：冰霜吐息跟随弹体；命中迸冰粒子。
- 端口连线：`source.cast → select.cast`、`select.targets → projectile.targets`、`element.cast → damage.cast`、`damage.cast → projectile.cast`、`projectile.entity → fx.entity`、`projectile.hit → particles.hit`。
- 预期：三发独立判定，贴脸三发全中；中距离只中 1–2 发。

### 2. 雷霆领域（`epic` / 5.0s）
- 触发：回合开始，延迟 0.6s。
- 目标：**一张「目标·范围」卡**：圆形半径 150、圆心跟随施法者、敌人数量 3、挑选规则血量最低（选择对象与数量写在范围卡上，不再另挂锁定卡）。
- 结算：闪电 12 + 12%，命中眩晕 0.3s / 0.8s；基础伤害 14。
- 表现：雷暴新星（冷色重调色板）跟随载体；命中爆发 60 半径、震屏 0.2。
- 端口连线：`source.cast → range.cast`、`range.hit → element.hit`、`element.cast → damage.cast`、`range.hit → fx.hit`、`range.hit → impact.hit`。
- 预期：站在对手附近开领域，优先打残血三人；适合反打近身。

### 3. 扇形霜爆（`rare` / 4.0s）
- 触发：回合开始，延迟 0.35s。
- 目标：范围扇形，半径 240、角度 100°、敌人数量 2、距离最近。
- 结算：冰霜 10，冻结 0.3 / 1.5s；基础伤害 12 + 击退 30。
- 表现：霜爆新星 + 命中爆发 80。
- 端口：`source.cast → range.cast`、`range.hit → element.hit`、`element.cast → damage.cast`、`range.hit → impact.hit`、`range.hit → fx.hit`。
- 预期：对手从正面冲进来会被扇形全覆盖；绕后则打空——需要玩家自己调整朝向。

### 4. 贯穿射线（`epic` / 5.0s）
- 触发：定时循环 3.4s，延迟 0.5s。
- 目标：范围射线，长度 1100、宽度 30、敌人数量 4、挑选规则最远。
- 结算：基础伤害 16 + 破甲 10；闪电 8 + 虚弱 20% / 2s。
- 表现：冰霜吐息挂在载体；沿路径撒电粒子。
- 端口：`source.cast → range.cast`、`range.hit → damage.hit`、`range.hit → element.hit`、`range.hit → particles.hit`、`range.hit → fx.hit`。
- 预期：一条线贯穿前后排，优先命中距离最远的 4 个。

### 5. 毒雾陷阱（`rare` / 4.0s）
- 触发：回合开始，延迟 1.2s。
- 目标：多目标，4 人，距离最近。
- 投递：区域残留，半径 120、持续 5s、每秒 7、减速 25%。
- 结算：持续伤害（6/s，跟随施法者，5s）；毒状态 35% / 4s。
- 表现：毒云跟随载体，存在 5s。
- 端口：`source.cast → select.cast`、`source.cast → zone.cast`、`zone.tick → damage.tick`、`zone.tick → status.tick`、`zone.area → fx.point`。
- 预期：先丢在对手必经之路，再打弹珠把对手往里推。

### 6. 荆棘壁垒（`common` / 2.5s）
- 触发：回合开始，延迟 0.2s。
- 目标：自身。
- 结算：护盾 70、持续 4s、反伤 35%。
- 表现：圣盾跟随施法者；金色粒子环绕。
- 端口：`source.cast → select.cast`、`select.targets → shield.targets`、`shield.cast → fx.cast`、`shield.cast → particles.cast`。
- 预期：用来扛住对手的一轮爆发，靠反伤换血；对高单发伤害最有效。

### 7. 回旋月刃（`epic` / 4.5s）
- 触发：回合开始，延迟 0.4s。
- 投递：投射物 1 发，速度 420，射程 700。
- 运动器：投射物绑定，弧线 60°、位移 260、0.8s、结束恢复原速、撞墙不消失。
- 结算：基础伤害 18 + 击退 20。
- 表现：重劈月刃（青色调色板）跟弹；拖尾粒子。
- 端口：`source.cast → select.cast`、`select.targets → projectile.targets`、`projectile.entity → motion.entity`、`motion.cast → damage.cast`、`projectile.entity → fx.entity`、`projectile.entity → particles.entity`。
- 预期：掷出后绕回，贴脸时能在去程/回程各命中一次。

### 8. 连锁闪电（`epic` / 5.0s）
- 触发：定时循环 3.2s，延迟 0.35s。
- 目标：单体，血量最低。
- 投递：指向性，瞬时，最大距离 900。
- 结算：闪电 12 + 眩晕 0.3 / 0.4s；基础伤害 10；分裂 3 道、扩散 360°、伤害 50%、射程 260。
- 表现：紫电新星跟随载体。
- 端口：`source.cast → select.cast`、`select.targets → targeted.targets`、`targeted.hit → element.hit`、`element.cast → damage.cast`、`targeted.hit → split.hit`、`targeted.hit → fx.hit`。
- 预期：先点掉残血，再靠分裂弹补周围。

### 9. 印记引爆（`rare` / 4.0s）
- 触发：回合开始，延迟 0.5s。
- 目标：多目标，2 人，距离最近。
- 结算：光印 2 层、上限 5、持续 4s、受伤加成 12%、到期引爆 30（半径 90）；基础伤害 6。
- 表现：金色火球命中爆发。
- 端口：`source.cast → select.cast`、`select.targets → mark.targets`、`mark.cast → damage.cast`、`mark.cast → fx.cast`。
- 预期：先叠印再靠普攻/其它果实触发，4 秒后自动炸；适合跟多段伤害果实搭配。

### 10. 延迟陨石（`epic` / 6.0s）
- 触发：回合开始，延迟 0.3s。
- 目标：多目标，3 人，距离最近。
- 延时：1.2s。
- 投递：区域残留，半径 140、持续 2s、每秒 10。
- 结算：基础伤害 30 + 击退 40；命中爆发 140 半径、震屏 0.3。
- 表现：陨石重劈（暖色调色板）跟随区域。
- 端口：`source.cast → select.cast`、`source.cast → delay.cast`、`delay.cast → zone.cast`、`zone.tick → damage.tick`、`zone.area → impact.area`、`zone.area → fx.point`。
- 预期：读对手走位提前 1.2 秒落点；落点范围内击退，可以把对手往墙边推。

## 设计口径

- **单体技能**只用 `select`（目标·单体）一张卡；**范围技能**只用 `range`（目标·范围）一张卡，选择对象/数量/挑选规则写在范围卡上，编译时 `C.select` 由范围卡兜底，不再需要「目标 + 范围」两张卡。
- 范围类样例的伤害/元素/状态都是技能级结算：它们按范围判定给出的目标集合结算；不需要再接一张锁定卡。
- 所有样例的边都带端口，画布上是橙（执行）/蓝（数据）/紫（事件）实虚线；旧果实那种没有端口的灰虚线是历史数据，重新连线后会变成彩色。
- 想改数值直接在卡片里改主参数，或点「全部参数 ⌄」在卡内改完整字段；改完点「试放」看范围圈与命中。
