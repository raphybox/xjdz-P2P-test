# 果实样例 · 像素特效定向 10 个

从 `vendor/pixelfx` 的 244 个代码像素特效里挑出**现有果实尚未使用**的 10 个，按当前端口化节点图（触发 → 目标 → 投递 → 表现 → 结算）做成可直接载入的果实预设。

入口：后台 `果实管理` → 左侧 `载入预设`。预设写在 `skill-modules.js` 的 `SM.PRESETS`，载入后可直接改参数、另存为正式果实。

## 1. 耀阳圣球（rare · 4.0s）

**链路**：`触发 → 目标(单体) → 投递(投射物) → 表现(日耀) → 结算(易伤+伤害+小爆)`

| 节点 | 关键参数 | 端口连线 |
|---|---|---|
| 触发·来源 | 循环 3.2s，首次延迟 0.4s，瞄准对手 | `cast → 目标.cast` |
| 目标·单体 | 最近敌人 / 1 个 | `targets → 投射物.targets` |
| 投递·投射物 | 1 发，速度 360，尺寸 10，射程 900 | `hit → 元素.hit` |
| 结算·元素 | 神圣 12，附加易伤 25% / 2s | `cast → 伤害.cast` |
| 结算·伤害 | 基础 10 | — |
| 结算·爆发 | 半径 45，35% 溅射，震屏 0.15 | `投射物.hit → 爆发.hit` |
| 表现·特效 | `holy/sunburst`，挂命中宿主，1.1 倍 | `投射物.entity → 特效.entity` |

**预期**：圣光球直线飞行，命中先挂易伤再结算，日耀环在目标身上炸开；适合做「起手标记」类果实。

## 7. 陨星火雨（epic · 6.0s）

| 表现·特效 | `fire/meteor`，挂命中宿主，1.5 倍 | — |

**预期**：读 1.1 秒后火雨落下，区域内持续掉血并被拖慢；爆发结算后再接陨星特效，避免特效先于判定。

## 验收

- `node tools/test_pixelfx_presets.js`：10 个预设存在、特效 id 均在 244 目录内、不与现有重复、图可编译、端口规则全部合法。
- 载入后每个图 5–7 卡、4–6 条边，触发 / 目标 / 投递 / 表现 / 结算五类齐全；表现卡均可从 `继续` 或命中事件口继续接。
- 数值为第一版可玩口径，不做最终平衡；后续可在卡片内直接调，不需要去右侧属性栏。
