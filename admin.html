键盘快捷键

在输入框里编辑文字时，除 Ctrl+S 外的快捷键会自动让位给浏览器原生编辑操作。地图撤销记录最多保留 60 步。

全局
Ctrl + S
保存配置到本地，游戏刷新后生效
? / F1
打开或关闭本面板
Esc
关闭弹层；在地图上取消本次绘制或取消选中
地图编辑器 · 撤销与重做
Ctrl + Z
撤销上一步地图编辑（Mac 用 Cmd）
Ctrl + Shift + Z
重做，等同 Ctrl + Y
地图编辑器 · 工具切换
V
选择工具（点击并拖动对象）
R / C
矩形 / 圆形障碍工具
1 / 2
出生点 1 / 出生点 2 工具
D / X
删除工具（点击画布上的障碍）
G
网格吸附开关，开启后绘制与拖动按 10px 对齐
M
对称轴开关：画一侧自动在对侧生成镜像障碍，移动 / 删除同步对侧
地图编辑器 · 选中对象后
Delete / Backspace
删除选中障碍（有镜像配对时会一并删除）
Ctrl + D
复制选中障碍（右下偏移 24px；对称开启时同时生成镜像）
方向键
移动选中对象 1px
Shift + 方向键
移动选中对象 10px
